# 场景类型速查

盘点时用来快速定调性 —— **不是用来查尺寸的**。尺寸不写进 `brief`（见
`references/how-to-write.md`：写多了会压掉图像模型的先验，图反而更差）。

这里只留能帮你**一句话说清一个地方是什么档次、什么气质**的东西。

---

## 一、身份定形制 —— 比尺寸有用十倍，但落笔要用大白话

一句"形制寒素而用料奢侈"胜过三行尺寸。中式古装可以按"身份"分个大概档次
（执政/亲王 → 府；六品以上官 → 宅；庶民含富商 → 家；官署 → 公字号），
档次越高，门第、装饰越可以繁复讲究；档次越低，形制越该收着，但可以在用料上砸钱。

**这张表只用来帮你自己想清楚"这地方该有多讲究"，不是抄写清单。**
判断完档次之后，落到 `brief` 里必须翻译成**通俗、图像模型认得出来的描述**，
不写专门术语 —— 哪怕它历史上准确。

★ 踩过：给一座皇室远亲府第写"门上是乌头门"，指望它传达"够格用最高规格的门"。
实测出图只是随手画了个牌楼式的门罩，跟真正的乌头门（两根黑漆立柱夹一道门、不连墙）
完全不是一回事 —— **图像模型压根没见过"乌头门"这个词该长什么样**，写了等于白写，
还占掉本该留给"府邸、庭院、旧而干净"这些强先验词的注意力预算。
"不用斗栱藻井"是同类问题的另一种形式：这是在要求模型画出"没有"某样东西，
扩散模型不擅长画否定，写了也不会体现在图里。**开间数、架数**（"五间进深九架"）
则属于材分制尺寸，本来就在 `references/how-to-write.md` 的"不写"清单里。

**正确做法是把判断结果翻译成看得见的对比**，不点名具体构件：

| 别写（专门术语 / 否定式 / 材分制数字） | 改写（通俗、可渲染的对比） |
|---|---|
| 乌头门 | 大门气派森严 |
| 五间进深九架 | 正厅面阔宽绰、屋檐深挑 |
| 不用斗栱藻井 | 梁柱柱头素净、没有精雕装饰 |
| 用重栱，梁栿施五彩遍装 | 梁栿粗壮，其上施着彩绘 |

**富户的正确演法**：宋代富商规避规制的办法是**不违形制而在材料上砸钱**
（沉香檀木作梁柱、釉砖铺地）。所以庶民富户的宅子是「**形制朴素、用料奢侈**」，
不是「什么都比别人大一号」—— 这是把"有钱"和"有身份"分开的关键，
这一条不需要点名具体构件也能表达：门面窄小 + 梁柱是南来的沉香檀木，够了。

《归来凤栖处》里就用上了：沈昭是员外（庶民富户），按宋制他家只能叫「沈**家**」，
剧本通用的「沈府」是越制，这条如实登记在 `note` 里；但慕容家是皇室远亲，"府"字够格，
到 `brief` 里只用"大门气派森严、正厅面阔宽绰"这类通俗描述带出来，不点名"乌头门"。

## 二、旧 ≠ 没人管 —— 三件事别混

| | 时态 | 与什么成正比 | 例 |
|---|---|---|---|
| **使用痕迹** | 过去（有人用过） | ∝ 使用强度 | 踩出的路径、绳槽、跪凹、磨露木色 |
| **在住迹象** | 现在（有人正住着） | ∝ 主人是否在场 | 满水的水缸、绢面完好的灯笼、修剪过的盆栽 |
| **失修** | 现在（**没人管**） | ∝ **1 / 主人财力** | 未清的落叶、主院长草、破损不补 |

**混了会出事**：给一座有仆役的「府」写「未清的落叶」「主院长草」，图里会读成废墟。
有仆役的宅子落叶当天扫、主院的草当天拔。

**最好用的组合是「磨得很旧、收拾得很干净」** —— 石阶被踩凹（用得久）+ 阶面无一片落叶
（有人扫），同时说出"有历史"和"有人管"。

痕迹只写**渲得出来**的那种：崩角缺棱、色差斑块、水渍带、缝里长草、发白路径、下沉错缝。
不写「手汗磨痕」「木纹被磨平」「漆面发亮」—— 微妙光泽在扩散模型里不可见。

## 三、三条最容易踩的中式古装时代错误 —— 只用来避雷，别把术语抄进 brief

1. **黄琉璃瓦** —— 宋代唯一釉色着色剂是铜（呈绿），黄釉作帝王专属是元明以后的事。
   别写"黄琉璃瓦"；写"深色瓦顶"或直接说"绿色"就够，不用点名"琉璃"。
2. **满屋顶琉璃** —— 宋代高等级屋面主体是乌黑发亮的深色瓦，不是满铺琉璃。
   通俗写法是「屋顶大片乌黑发亮，檐口露出一线绿色」—— 不需要"青掍瓦""剪边"
   这两个词，图像模型不认得这两个术语，但认得"乌黑发亮的瓦""绿色檐口"。
3. **清式宽大屏背太师椅** —— 宋代太师椅是**带荷叶托首的圆后背交椅**。
   宋代可用：靠背椅、扶手椅、交椅、帐床（三面围子）、黑漆围子榻、屏风 ——
   这几样本身就是常见词，不用再翻译。

**这三条不是考据，是避免出戏的清单**，成本为零而收益是不让观众一眼看出穿帮。
但"避雷"和"炫技"是两回事 —— 避雷只需要**不写错的词**，换成最通俗的说法，
不需要再换上一个"更精确"但模型更陌生的专门术语。

## 三之二、★ 位置错配避雷清单 —— 器物长在哪儿

这一节与上面三条时代错误同性质：**只用来避雷，成本为零。** 它防的不是"词不对"，
而是**位置不对** —— 那是另一种、而且更糟的错误：生僻词模型会忽略，
**位置反常它会按自己的先验画到别处去**。锚点最怕这个，因为锚点唯一的职责就是位置一致。

| 器物 | 它真正长在哪 | 别写成 |
|---|---|---|
| 石狮 / 石雕瑞兽 | 大门两旁（镇宅狮）· 殿前（宫廷狮）· 栏杆望柱**头上** · 拴马桩**柱头上** | **廊柱下** —— 廊柱是结构柱，柱脚只有柱础 |
| 抱鼓石 / 门枕石 | 门槛两端，夹住门框门轴 | 露天台阶两侧 |
| 柱脚 | 只有柱础（覆盆、莲瓣、卷草一类的雕饰） | 蹲一对独立石兽 |
| 台阶两侧 | 垂带石；高等级另有勾栏与望柱 | 抱鼓石 |
| 拴马桩 | 门外街沿 | 院内 |

★ 石狮这条的源头能解释整个规律：习俗来自**唐代坊门的夹柱石**（后演化为抱鼓石），
所以它天生长在"**需要被守的开口**"或"**柱子顶端**"。判断一件器物该在哪，
先问它当初是为什么存在的 —— 而不是"这种档次的宅子该有什么"。

**这张表不求全。** 撞上没列进来的器物，办法是**换一件痕迹类的**
（见 `references/how-to-write.md` 三之三那条优先级：能用痕迹就别用有规制的器物），
不是去把这张表补成考据手册 —— 那会把整个 skill 拖回它已经走偏过的那个方向。

## 四、常见空间的调性一句话

| 空间 | 一句话抓住它 |
|---|---|
| 勋戚府第院落 | 讲究、有仆役日日打理、磨得很旧但收拾得干净 |
| 庶民富户宅院 | 形制寒素而用料奢侈；仆役不多，主路干净而墙根有草 |
| 宫廷殿庭 | 等级最高、内侍日日洒扫，旧只旧在石与墙、不旧在整洁 |
| 官署公堂 | 用了太多年，痕迹全在受审那一片（跪毡处磨出浅凹） |
| 宫内劳作院落 | 全片使用痕迹最重的地方：泼水泛出碱霜、井圈绳槽极深 |
| 罚役院 / 破屋 | 形制最低也最破败：泥皮成片脱落、屋面塌陷、素土地面 |
| 都城街巷 | 宋代已废里坊，店铺直临街；街心石条被车辙磨出两道浅槽 |
| 临街楼阁挑台 | 三面设栏上有檐，楼下是街市；靠栏一线被踩得发白 |

## 五、怎么维护这份速查

只往里加**跨项目能复用的调性判断**，或**位置错配避雷**（第三之二节），
不加尺寸、不加材料清单、不加道具表。
判据一句话：**这条能不能帮我用一句话说清一个地方是什么档次，而且这句话本身
就是通俗、图像模型认得出来的说法？** 两条都要满足 —— 术语再准确，模型没见过
就不进；不能说清档次的大白话，也不进。

避雷清单那一节的判据不同，是：**这条防的是不是"位置/年代错了、观众或模型一眼看出不对"？**
是就进，且只写"真正长在哪 / 别写成什么"两栏，**不写为什么长在那儿的考据**。
