# 角色服装类型速查

盘点时用来快速定**这个人该穿多讲究** —— **不是用来查服制术语的**。
术语不写进 `brief`（见 `references/how-to-write-character.md` 第五节：
图像模型没见过的词跟写尺寸一样是纯粹噪声）。

这份表与 `scene-archetypes.md` 完全同构：**判断照做，落笔用大白话。**

---

## 一、身份定服制 —— 判断用，落笔要翻成通俗描述

中式古装大致按**层数 · 料子 · 工 · 配饰**四样分档，越高越多、越软垂、越细、越成套。
但这四样都能用大白话说，**用不着点名任何一个服制术语**。

★ 与场景那边"乌头门"是同一个坑：写"襦裙"指望模型知道那是什么，
实测它画出来的是一件泛泛的古装长裙 —— **它压根没见过这个词该长什么样**，
还占掉了本该留给"长裙""腰线很高""料子软垂"这些强先验词的注意力预算。

| 别写（服制术语） | 改写（通俗、可渲染） |
|---|---|
| 襦裙 | 上身短衣、下身长裙，腰线提得很高 |
| 褙子 | 对襟长外衣，两侧从腰下开衩，不系带 |
| 直裾 / 交领右衽 | 交领长袍，衣襟一直裹到身侧 |
| 幞头 | 黑色软帽，脑后垂下两条带子 |
| 蹙金绣 / 五彩遍装 | 绣线里掺着金线，纹样微微凸起 |
| 五品官服 | 朱红圆领窄袖官袍，腰上一条素带，胸前没有纹样 |
| 短褐 | 粗麻短上衣配裤子，袖口收紧 |

**「形制朴素而用料奢侈」这条对衣服比对建筑更好用。** 庶民富户规避规制的办法是
不动形制、在料子上砸钱：**形制寻常而缎面厚亮**、鞋是寻常样式而底子是新的。
这就把"有钱"和"有身份"分开了，一个术语都不用。

**颜色照写。** 固有色是识别特征，不是配色方案 ——
"朱红官袍""藏青夹克""洗旧的蓝白校服"都该写；
"整体偏冷""低饱和""蓝占七成"不许写。理由见
`references/how-to-write-character.md` 第七节。

## 二、旧 ≠ 没人管 —— 衣服版，三件事别混

| | 时态 | 与什么成正比 | 例 |
|---|---|---|---|
| **使用痕迹** | 过去（穿过很多次） | ∝ 穿的次数 | 领口袖口磨白、膝头起亮、鞋头蹭掉一片 |
| **在穿迹象** | 现在（现在有人打理） | ∝ 有没有人替他收拾 | 洗得干净、褶子是熨过的、扣子一颗不缺 |
| **失修** | 现在（**没人管**） | ∝ **1 / 财力** | 破口不补、缺一颗扣子、下摆脱线 |

**混了会出事**（跟给有仆役的府第写"主院长草"是同一个错）：
给一个富户角色写"下摆脱线、缺一颗扣子"，图里会读成落难 —— 有钱人的衣服破了会换会补。
反过来，给一个穷角色写"熨过的褶子"也不对。

**最好用的组合是「洗得发白而没有一个破口」** —— 说出"穿了很多年"和"有人打理"两件事，
对应场景那边的"磨得很旧、收拾得很干净"。

痕迹只写**渲得出来**的那种：磨白、起毛、破口、水渍、油污、褪色、鞋底磨偏。
不写"手感变软""包浆""光泽内敛" —— 微妙质感在扩散模型里不可见。

## 三、最容易踩的服装时代错误 —— 只用来避雷，别把术语抄进 brief

**中式古装**

1. **明清式立领与一排布纽** —— 宋及以前是交领或圆领，立领配纽扣是明中后期以后的事。
   写"交领"就够，不用点名任何形制词。
2. **鲜艳大面积明黄** —— 与"黄琉璃瓦"同源，黄作帝王专属是元明以后。宋写朱、绛、青、紫。
3. **满身刺绣** —— 高等级也是**局部**精工（领缘、袖口、下摆一道），不是通身铺满。
   写"领缘和袖口一道细绣，别处素净"。

**现代年代戏**（短剧常撞）

4. **面料穿越** —— 1990 年代是化纤、涤棉、垫肩很高、翻领很宽；速干、莱卡、无痕是 2010s 之后。
5. **成套感穿越** —— 早年是"能穿就行"的混搭；整套统一配色的工装是近年的事。

**这几条不是考据，是避免出戏的清单**，成本为零，收益是不让观众一眼看出穿帮。
但避雷只需要**不写错的词**、换成最通俗的说法，不需要再换一个"更精确"而模型更陌生的术语。

## 四、常见角色的调性一句话

| 角色 | 一句话抓住他 |
|---|---|
| 世家小姐 | 层数多、料子软垂、绣工细而不扎眼；干净到看不出穿过几次 |
| 庶民富户之女 | 形制寻常而缎面厚亮 —— 钱花在料子上，不敢花在形制上 |
| 官员居家 | 一件素色宽袍、腰间无带；只有一枚玉扣是讲究的 |
| 内侍 / 杂役 | 形制最简、颜色最沉，袖口收紧便于干活；肘与膝磨得最重 |
| 兵卒 | 皮革与布混着穿，绑带多；所有边缘都磨圆了 |
| 落难的世家人 | 料子仍是好的、形制仍是对的，但**破了没补**——这三样同时出现才是落难 |
| 1990 年代小老板 | 高垫肩西装、皮带扣很大、皮鞋擦得亮，袖长却不合身 |
| 现代产线工人 | 成套工装、反光条已褪、口袋边缘起毛，安全鞋鞋头磨出金属色 |

## 五、怎么维护这份速查

只往里加**跨项目能复用的调性判断**，不加尺寸、不加服制术语表、不加配饰清单。
判据一句话：**这条能不能帮我用一句话说清一个人该穿多讲究，而且这句话本身
就是通俗、图像模型认得出来的说法？** 两条都要满足 —— 术语再准确，模型没见过就不进；
不能说清档次的大白话，也不进。
