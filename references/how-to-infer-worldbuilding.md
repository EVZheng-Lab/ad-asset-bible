# 动笔前先定调性 —— 年代 / 阶层 / 风格 / 地理位置 / 人种

> 场景篇在 `how-to-write.md`，角色篇在 `how-to-write-character.md`，道具篇在
> `how-to-write-prop.md`。**这一份比它们都靠前** —— 三类资产的 brief 写得对不对，
> 全靠这一步先定下来的基调，判断错了，后面写十份 brief 错十份。

---

## 一、这一步为什么存在（实跑《北王刀》踩出来的）

给《北王刀》盘点场景时，第一版把"苏家客厅"写成：

> ✗ 整体装修**传统偏旧**，木质家具居多。

听起来像一座老式中式住宅。但通读全剧后发现：这个故事的物质文明其实是**当下**——
剧本里出现的是伦敦苏富比拍卖行、世界银行发行的黑金卡、兰博基尼 Aventador、写字楼、
智能手机通话，全是当代真实世界的品牌与机构；而苏家只是个"几乎要跌出三流"的没落
世家，苏怀瑾这一房又是被罚到只剩死工资的那一支。她家该是**当代都市高端小区里的
跃层公寓**，不是任何年代的中式老宅。

错的原因不是没查资料，是**没有先定基调就凭直觉写**——看到"苏家""世家"这两个词，
第一反应就往"古旧中式"上靠了。而这个故事里，"世家""老太君""异姓王"这类词只是
一套架空的**政治军事身份体系**，跟物质生活是不是古代，完全是两件事。

---

## 二、五件事，分别怎么定

### 1. 年代 —— 找真实世界的品牌/机构/科技当锚点

**架空称谓不能证明年代，真实品牌/机构才能。** 很多都市异能/赘婿/战神类短剧是
"现实物质生活 + 架空政治军事体系"两条线并存的结构：国名、官职、军职可以是编的
（"大夏""北莽""天策上将军""兵部"），但汽车、拍卖行、银行、通讯方式往往是**原样
照抄现实世界**的，因为编剧没有必要为这些编一套新词。

判断顺序：

```
第 1 步  扫一遍剧本，找有没有真实世界的品牌 / 机构 / 城市名（伦敦、纽约、苏富比、
        世界银行、具体车型、具体奢侈品牌），这些是最强的年代锚点
第 2 步  如果有，且都是当代款（现在市面上买得到的车型、当下还在运营的机构），
        物质文明层直接按"现在"处理，不用管国名官职是不是架空的
第 3 步  如果剧本里一个真实品牌/机构都没出现，只能退回去看科技细节
        （手机是不是智能机、有没有网约车/外卖这类当代生活方式），
        同样只定"大概哪个年代"，不深挖精确到哪一年
```

**反例（这条最容易犯）**：看到"天策上将军""兵部""总督"这类词，就直接判定
"这是古代剧"或"这是架空古代朝代剧"，然后把所有场景都套上古风描述。
这些词只说明**政治军事身份体系**是架空的古代式的，不代表主角开的车、住的房子、
用的银行卡也是古代的——这两层要分开判断，见第三节。

### 2. 阶层 —— 抓具体数字与比较，别被自称的身份词牵着走

**身份词会骗人，数字不会。** "世家""老爷""大人物"这类词只是剧本给的**称谓**，
不能直接当成阶层结论抄进 brief。要抓这几类更硬的证据：

| 证据类型 | 《北王刀》里的例子 |
|---|---|
| **总资产的具体数字** | "苏氏拢共也就三亿资产"——这是苏家全部身家的账面数字 |
| **跟故事里其他角色的量级差** | 对比北辰集团随手就是"两万亿"的项目、世界银行全球
只发五张的黑金卡、七百多万一辆随手送人的跑车——三亿在这个故事的坐标系里并不算多 |
| **外部人物怎么评价这家人的地位** | 楚右慈原话："你们一个**几乎要跌出三流**的
小家族"——故事结局给出的最终定性，比中途的自称更权威 |
| **家族内部不同分支的贫富落差** | 同一个"苏家"，一支靠分红随手买宝马，另一支被
罚到骑电动车上班——不能把"苏家"当成一个统一的阶层来写，要分支系判断 |

**判断结论要放进"故事内部的坐标系"，不要直接套用外部真实社会的阶层标签。**
一句"总资产三亿"放到现实社会里已经是"财富自由"，但放到这个故事里，是所有出场
"有钱人"里垫底的一档，随时可能被更高阶层的角色一句话打回原形。**brief 的调性要
按故事内部坐标系写**（"这家人在剧里是没落但仍在挣扎维持体面的世家"），不要按外部
标签写（"这家人财富自由，家里应该极度奢华"）——两种写法会指向完全不同的美术调性。

### 3. 风格 —— 分清"现代物质生活"与"架空政治军事体系"是两条平行线索

同一个人物，可能在不同场景切换调性：崔总督、袁左宗这类角色，日常场景里是西装、
写字楼、豪车；到了涉及"天策上将军""武烈军"这类军职身份的场景，则可能换上更具
古代军政色彩的装束或排场。**这不是矛盾，是两条线索各管各的场景**：

```
判断这一句 brief 该用哪条线索，只问一件事：
这一场戏，人物此刻是以"现代身份"（老板/上班族/亲戚）出现，
还是以"架空军政身份"（统帅/天王/王妃）出现？
```

不能因为整部剧的世界观里有架空军政体系，就把所有场景都写成古风；也不能因为
主线大部分时间是都市日常，就把涉及军政身份的场景也写成纯西装写字楼风——
要按每一场戏具体判断。

### 4. 地理位置 —— 找真实地名/机构/行文线索，没有就按题材给默认

**这一条最容易被漏**：剧本里很少有台词专门交代"这是中国""这是哪个城市"，
地理位置几乎总是默认设定、需要主动判断，而不是等着剧本明说。

判断顺序：

```
第 1 步  扫一遍剧本，找真实地名 / 机构 / 地标建筑（城市名、行政区划、
        海关/公安/法院这类机构名）、方言习惯用词、货币单位（人民币/美元）
第 2 步  找到了，直接按这个地区处理；剧本里出现的品牌/机构信息
        （年代判断时已经扫过一遍）往往也能同时印证地理位置，两步可以合并看
第 3 步  剧本里一个真实地名都没出现（多数架空古代剧、纯都市短剧都是这样），
        按题材给一个默认：国产短剧不特别说明时，默认中国大陆——
        当代都市或中式古代/架空王朝，不要凭感觉换成别的国家/地区
```

定错地理位置的代价：场景的建筑风格、街景、招牌文字全会跟着跑偏——图像模型
对"一条商业街"的先验默认值不确定，可能出来的是任何一个国家的街景，除非
明确点出"中式招牌""中文字样"这类锚点。

### 5. 人种 —— 由地理位置结论直接推出，例外写进角色底档的 note

**人种跟地理位置是同一件事的两面**：故事发生在中国，演员默认就是中国人/东亚
人种；发生在剧本里出现的另一个真实国家，演员默认换成那个国家的主流人种。
这条结论写进 `meta.worldview`，作为全片默认基调，不需要每个角色重复判断一遍。

**例外单独处理，不动全局默认**：剧本如果明确写了个别角色是混血、外籍、留学生、
异国配偶这类身份，这个例外只写进**那个角色底档自己的 `note`**，其余角色仍按
全局默认处理——不要因为剧本里有一两个这样的角色，就把整体基调改成笼统的
"多种族"或"国际化都市"，那样反而让大多数角色的人种变得不确定。

**这一条最终要落进底档 brief 里"XX岁女性/男性"那句要不要点出人种**：
不写清楚，交给下游生图时它会自己猜一个默认值，容易出现同一部剧里不同角色
人种前后不一致、或者角色人种跟场景所在的地理位置对不上的情况。

## 三、★ 同一个家族名下可能有多处地产，规格不同

去重时最容易连带出错的地方：剧本里出现好几处名字相近的"客厅"/"家中"，
不能只看名字表面相似就合并，也不能想当然拆开——要靠两条硬证据交叉验证：

1. **在场人物**：这一场戏里，家族里地位最高的那个人（族长/老太君一类）
   在不在场？如果只出现小辈自己的核心家庭成员，很可能是分支自住的地方，
   不是祖宅
2. **空间限定词**：剧本用的是"院子"还是单纯的"客厅/家中"？带院子/别墅字样的，
   大概率是规格更高的祖宅或主宅；反复出现却从没提过院子/大门的，大概率是
   普通住宅单元（公寓/跃层）

《北王刀》的实例：苏老太君的"苏家院子"（有正经院子，只她在场）和苏怀瑾自己的
"苏怀瑾家客厅"（从没提过院子，只她的核心家庭成员在场）是两处完全不同规格的地产，
名字都带"苏家"两个字，但不能合并成一份场景资产。

## 四、这一步的产出形式

**不产出单独的世界观文档，但结论要写进 `meta.worldview`。** 判断结果既要体现在每句
brief 的用词和调性里，也要在 `meta.worldview` 里留几句话的结论——这一步的意义太大，
只留在聊天记录里等于没有记录：页面顶部剧本路径正下方专门有一块高亮条显示它，使用者
点开页面第一眼就看得到。年代判断决定电器/交通工具的款式基调，阶层判断决定装修是
"讲究"还是"寒素"，风格判断决定这一场戏该用现代线索还是架空军政线索，**地理位置
判断决定场景的建筑/街景基调，人种判断决定角色底档 brief 里要不要点出、点出哪种
人种**——五件事的结论都要进 `meta.worldview`，不是只写年代/阶层/风格那三样。

个别角色的人种例外（混血、外籍、留学生这类剧本明确写了的）不算全局结论，
不进 `meta.worldview`，写进**那个角色底档自己的 `note`** 就够了。

吃不准的判断依据，跟去重、锚点一样，写进对应资产的 `note` 里，让人能复核
（例："苏家客厅装修基调按当代都市高端公寓处理，依据是剧本出现的真实品牌/机构，
而非苏老太君祖宅那种更古旧讲究的调性"）。★ 依据里只引用**剧本自己的证据**（台词、
场次号），不要引用"上面那张截图""如图所示"这类只有当次对话才懂的说法——`note` 跟
`meta.worldview` 一样，脱离对话也要能读懂。`meta.worldview` 只写结论本身（几句话，
build.mjs 会拒绝空着的），依据留给各资产的 `note`；第 9 步汇报时同样要点出这条判断，
跟页面上那句结论保持一致。

---

## 五、这不是深度考据

`SKILL.md` 的边界里写着"不做深度考据"——这一步不违反那条边界。深度考据指的是
去查历史资料还原某个具体朝代的器物形制（这仍然禁止，见 `scene-archetypes.md`）；
这一步只是**读剧本自己给出的线索**（品牌、机构、数字、称谓、在场人物），
不需要额外查资料，五分钟内就能定出"大概"，跟"年代与国别定个大概、不出戏就行"
是同一件事，只是把判断方法说清楚，免得凭直觉套错。
