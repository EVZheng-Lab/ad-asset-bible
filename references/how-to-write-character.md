# 怎么盘点角色

> 场景那份在 `how-to-write.md`，道具那份在 `how-to-write-prop.md`。
> 三份共用的纪律（只写需求不写为什么、300 字上限、每一格单独读懂、不写下游的活）
> 写在 `how-to-write.md`，这里只写角色特有的。

---

## 一、三层压成两层：为什么"服装"才是出图单元

角色天然是三层：**人 → 他的几套服装 → 每套服装的几个状态**。
落到这份盘点里是这样：

| 层 | 落到哪 | 例 |
|---|---|---|
| 人（脸、年龄、身形、发型） | `characters[]` **底档**，写一遍 | `@char_xiaoming` 小明 |
| 人 + 一套服装 | `outfits[]` **资产**（出图单元） | `@char_xiaoming_xuesheng` 小明 · 学生装 |
| 那套服装坏了/脏了 | `outfits[].variants[]` **状态变体** | `..._xuesheng_hurt` 受伤破损 |

**为什么中间那层才是资产：光有一张脸出不了图，他必须穿点什么。**
所以底档**不登记场次**（它不是出图单元），场次全部登记在服装资产上。
`build.mjs` 会拦「底档写了 scenes」和「底档没有任何服装资产」两种写法。

**为什么底档要单独一份、而不是每套服装各写一遍脸：**
官方把 character drift 列在 `environment invention` 之后的第二位漂移源。
同一张脸写三遍，三遍之间必然对不齐 —— 那就是漂移。底档是脸的**唯一权威版本**，
页面上服装格的「复制」会自动把「底档 + 这套衣服」拼起来给你，所以不必也不许重复写。

## 二、★ 换整套衣服不是变体，是另一份资产（与场景那条同构）

场景那边的判据是「主场景那个空间，在这个变体里还在画面里吗」。角色这边换个词：

> **这套衣服，在这个变体里还穿在身上吗？**

| 变化 | 图生图有共同像素吗 | 判定 |
|---|---|---|
| 同一套衣服撕破 / 湿透 / 蒙尘 / 染血 | 有 —— 那套衣服还在画面里 | ✓ 状态变体 |
| 换一整套衣服 | **没有** —— 脸还在，衣服一个像素都不剩 | ✗ 另建一份服装资产 |

换装的代价跟场景那个坑完全一样，也是双份的：
使用者拿这套衣服的图去做图生图编辑，而两张图除了脸毫无共同像素，编辑必然失败；
而且**盘点上会漏掉一套真实要拍的服装** —— 藏在变体里就不会被当成一份资产去出图。

`build.mjs` 拦最露骨的写法（`另一套 / 另一身 / 换一套 / 换一身 / 整套换 / 换成另 / 改成另一`）。
词表抓不全 —— 每写完一个状态变体，回头问一句"那套衣服还穿在身上吗"。

**换装与状态可以叠。** 小明有学生装和西服两套，学生装还有个受伤破损版 ——
那是两份资产、其中一份带一个变体，不是"三套服装"也不是"一套服装三个变体"。

## 三、收录门槛：跨场景 / 有名有姓才建

与道具同一条尺子，也与「一个中式庭院」同一条理由：
**只有跨场景复用的形象才有漂移风险，才值得建资产锁。**

| 收 | 不收 |
|---|---|
| 主角、反派 | `3-1` 的卖菜大娘 |
| 贯穿全片的配角（跨 ≥2 场） | `12-2` 围观群众、酒楼里的甲乙丙 |
| 剧本给了名字的 | 只出现一场、剧本连称呼都没给的 |

一次性配角交给图像模型的先验就行（"一个五十来岁的卖菜妇人"，它画得比我们写得好）。
但**要在汇报里如实点一句「另有 N 个一次性配角未建档」** —— 盘点的价值在账目诚实，
悄悄不算等于账目有洞。

## 四、底档 brief 怎么写 —— 只写跨服装不变的那部分

写这四样，全部是**画面里看得见、而且换了衣服也不会变**的：

1. **年龄段与性别** —— "二十七八岁男性"、"二十出头女性"
2. **脸** —— 脸型、颧骨、鼻梁、下颌线，加**一处独有的辨识点**（左眉尾一道旧疤、
   右颊一小片浅色胎记）。这一处是抗漂移的锚点，跟场景的参照物是同一件事
3. **头发** —— **发质与大致长度**（浓密柔顺、及腰；黑而硬、及肩）。
   ★ 梳法不写在这里 —— 同一个人出嫁时全部盘起、当宫女时只在脑后拢住，
   梳法是跟着服装变的，写在**服装那一格**。发饰同理（发饰本来就是配饰）。
   实跑《归来凤栖处》时就撞上了这条：沈云卿一个人四套服装、四种梳法
4. **身形** —— 结实/瘦削/瘦小、肩宽、高矮

**不写五官比例。** "眼距为脸宽的五分之一"跟给场景写"墙下隔减广约 1.09m"是同一个错：
扩散模型渲不出来，纯占注意力预算，而且它对"二十七八岁男性方脸"的先验极强，
穷举反而把先验压掉。

## 五、服装 brief 怎么写 —— 只写这一套衣服

脸在底档里，这一格**从第一个字起就是衣服**。写这四样：

1. **形制** —— 什么衣什么裤什么鞋，领子怎么样、扣子拉链在哪、层数
2. **料子与做工，用通俗说法** —— 粗棉布 / 手编毛线 / 翻毛皮 / 化纤，
   针脚齐整还是歪扭。跟场景那条一样：**判断档次照做，写出来必须是通俗对比，
   不是档次结论也不是术语**（"襦裙""直裾""褙子"这类词图像模型多半没见过，
   写了跟写尺寸一样是噪声 —— 见 `knowledge/costume-archetypes.md`）
3. **一两处最有说服力的使用痕迹** —— 右膝和口袋边缘磨得起毛发白、
   裙摆一道洗不掉的水渍、鞋头蹭出一片灰痕。
   注意「旧 ≠ 没人管」这条对衣服一样成立（见 `scene-archetypes.md` 第二节）：
   有钱人的旧衣服是**洗得发白但没有破口**，穷人的旧衣服是**破了不补**
4. **（推荐，不强制）参照物一件** —— 不摘的那件配饰：腰上那条帆布工具带、左手腕那块方形钢壳表、
   颈上细红绳挂的小铜环。`build.mjs` 已不再要求服装 brief 里出现"参照物"三个字 ——
   第 3 点的"使用痕迹"本来就是能跨镜头识别的细节，再强制加一句容易逼出「那圈洗得发白的
   袖口是认得出的参照物」这种为了凑闸门而复述一遍的废句。这一件配饰仍值得写
   （尤其换装频繁、光靠痕迹不够好认时），想写就按下面的方法推导；不写也不算漏项。

   **推导顺序与场景锚点完全相同**（三步 + 五条判据，见 `how-to-write.md` 三之三），
   只是载体从"空间里的物件"换成"身上的配饰"：

   ```
   第 1 步  这套服装出现的那几场，人在干什么？（读 Δ 动作行）
   第 2 步  那个动作下，身上哪一件不摘的东西是**看得见**的？
   第 3 步  过五条：不可移动（不摘）/ 唯一 / 好认 / 画面里看得见 / 位置天然
   ```

   ★ **服装锚点多一条陷阱：会被姿态挡住。** 「腰侧那枚素银小铃」在站姿里很好，
   但这套衣服的戏全是**跪着接旨**，腰侧被身体和裙摆挡死 —— 它就不是这套的好锚点，
   该换成跪姿里仍然看得见的（发间、袖口、领缘）。
   踩过的另一个：「衣领**内侧**缝着的名字布牌」—— 任何姿态下都不入画，第 4 条直接不过。

   ★ **优先用痕迹，别用有规制的器物**（同 `how-to-write.md` 那条优先级）。
   审计发现雷区集中在这里：扳指（作日常饰物是清代的事）、翡翠镯（缅甸硬玉，清代才流行，
   宋代用和田玉）、方形胸章（明代补子，且是绣的不是金属牌）、「家纹」（那是日语，
   中式说族徽/字号）。而磨痕、绳印、镣铐痕、普通布带这类**一个都没出问题** ——
   因为它们不需要专门知识。

## 六、★ 三条不写（角色专有，最容易复发）

| 不写 | 为什么 |
|---|---|
| **表情、情绪、眼神、神情** | 角色资产图是**中性站姿的形象底板**，不是一个镜头。写了等于把只能用在一个瞬间的图当成全片的形象基准 |
| **姿势、动作、手势、站姿坐姿** | 同上，是 Lira 与 CINEDANCE 每个镜头各自的活 |
| **性格评语**（温柔、高冷、精明、气质、看起来很…） | 渲不出来，跟场景那边写"讲究/寒素"是同一类错误 |

要表达"这人不好惹"，写**看得见的东西**：下颌线硬、衣领扣到最上一颗、指节有旧伤。
不写"高冷"。`build.mjs` 有 `EMOTION` 与 `TRAIT` 两张词表兜底，但**词表抓不全，
动笔前就别写**。

场景那边的 `PEOPLE` 词表（人物/角色/众人…）**不管角色表** ——
角色资产图里当然要有人。那条闸门只扫场景，是刻意分派的。

## 七、颜色到底能不能写 —— 能，固有色可以，配色方案不行

这一条与 `handoff-boundaries.md` 早前的写法有出入，以这里为准，理由三条：

1. **闸门本身就划在这条线上。** `DOWNSTREAM` 拦的是 `色相 / 色调 / 饱和度 /
   偏暖 / 偏冷 / 对比度 / 调色 / 影调` —— 全是**配色方案**的词汇，一个颜色名都没拦。
2. **Lira 的 `never invent a palette over them` 说的是色卡**，不是一件衣服本来什么颜色。
3. **抽掉颜色，角色一致性就没了。** "洗旧的蓝白校服"是可验证的锚点；
   只写"洗旧的校服"，同一个角色两次生成会连衣服颜色都不一样 —— 那正是要防的漂移。
   `scene-archetypes.md` 也早就在建议直接写"绿色""乌黑发亮"。

所以：**"深蓝色粗棉布工装""藏青夹克""浅色手编毛衣"照写**；
**"整体偏冷""蓝占七成""低饱和"不许写** —— 那是 color-script 与 Lira 的活。

## 八、写完自查五句

1. 底档里有没有混进只属于某一套衣服的东西（发饰、围巾）？
2. 服装格里有没有重复写脸？（重复了就等于三个版本的脸）
3. 每个状态变体，那套衣服还穿在身上吗？
4. 有没有表情、姿势、性格？
5. 写了参照物吗？写了的话，是一件**不摘**的东西吗？
   **这套衣服的戏是什么姿态，那件东西在那个姿态下看得见吗？**（不写不算漏项，见五之四）
6. 参照物是"痕迹类"还是"有规制的器物"？是后者的话，位置和年代都站得住吗？
